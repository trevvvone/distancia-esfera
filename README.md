# Distancia entre dos puntos de una esfera

Demo funcional, calcula la distancia entre dos puntos de la Tierra a partir de su latitud y longitud.

## Fórmulas implementadas
- Haversine
- Ley esférica de cosenos
- Aproximación equirectangular
- Rumbo inicial (bearing)

## Qué muestra
- Coordenadas del punto A y del punto B
- Distancia en km y millas con cada método
- Diferencia respecto a Haversine, ángulo central y rumbo

## Tecnologías
Next.js, React y JavaScript, sin librerías adicionales. Desplegado en Vercel.
